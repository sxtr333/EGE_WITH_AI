# №1 · Решение прямоугольного треугольника
Источник: 50 задач Решу ЕГЭ (category 79), формулы выписаны из решений.

---

## Узнать
В условии: угол 90° / катет / гипотенуза / sin / cos / tg / высота CH / медиана / биссектриса.

Обозначения (как на сайте):
- `C = 90°`
- `AB` — гипотенуза
- `AC`, `BC` — катеты
- `CH` — высота к гипотенузе, `H` на `AB`

---

## База (нужно почти всегда)

| Что | Формула |
|---|---|
| Пифагор | `a² + b² = c²` |
| Синус | `sin α = (противолежащий катет) / гипотенуза` |
| Косинус | `cos α = (прилежащий катет) / гипотенуза` |
| Тангенс | `tg α = (противолежащий) / (прилежащий)` |
| Связка | `tg α = sin α / cos α` |

---

## Тождества (без них дыры)

| Когда в условии | Что достать |
|---|---|
| Дан `sin`, нужен `cos` (или наоборот) | `sin²α + cos²α = 1` → `cos α = √(1 − sin²α)` |
| Дан `tg`, нужен `cos` | `1 + tg²α = 1/cos²α` → `cos²α = 1/(1+tg²α)` |
| Дан `tg`, нужен `sin` | `sin²α = tg²α / (1+tg²α)` |

---

## Типовые ходы (стороны ↔ тригонометрия)

1. Дан катет + `sin/cos/tg` → сразу определение → искомая сторона  
2. Дан `sin`, а нужен другой катет → сначала `cos` из `sin²+cos²=1`, потом определение  
3. Даны два катета → Пифагор → гипотенуза → `sin/cos/tg`  
4. Углы: `A + B = 90°` → `sin A = cos B`, `tg A · tg B = 1`

---

## Высота к гипотенузе (`CH`)

Это отдельный частый кусок банка. Без этих формул часть задач не решается.

| Формула | Смысл |
|---|---|
| `∠A = ∠HCB` | острые углы с взаимно перпендикулярными сторонами |
| `AH = AB · cos²A` | проекция катета `AC` |
| `BH = AB · sin²A` | проекция катета `BC` |
| `CH = AB · sin A · cos A` | высота |
| `CH = AC · sin A` или `CH = BC · cos A` | через катет |
| `CH² = AH · BH` | высота = среднее геометрическое проекций |
| `AC² = AH · AB` | катет = среднее геометрическое гипотенузы и проекции |
| `BC² = BH · AB` | то же для второго катета |
| `AH = CH / tg A`, `BH = CH · tg A` | если дан tg |

---

## Площадь

`S = (1/2) · катет₁ · катет₂`

---

## Углы 30° / 45° / 60°

- напротив 30° катет = **половина гипотенузы**
- `sin 30° = 1/2`, `cos 30° = √3/2`, `tg 30° = 1/√3`
- `sin 45° = cos 45° = √2/2`, `tg 45° = 1`
- `sin 60° = √3/2`, `cos 60° = 1/2`, `tg 60° = √3`

---

## Медиана / биссектриса из прямого угла

| Факт | Формула |
|---|---|
| Медиана к гипотенузе | `CM = AB / 2` |
| Биссектриса прямого угла | делит 90° на `45° + 45°` |
| Угол между биссектрисами острого и прямого | `(90° + острый) / 2` |
| Угол между биссектрисами двух острых | всегда `45°` |

---

## Как открывать задачу

1. Есть только стороны / sin / cos / tg? → **База + тождества**  
2. В условии `CH` / высота? → блок **Высота**  
3. Просят площадь? → `S = ab/2`  
4. Углы, биссектриса, медиана? → блок **Медиана / биссектриса** + `A+B=90°`

---

## Чего не хватало в ChatGPT-PDF (и есть в реальных решениях)

- `sin² + cos² = 1`
- `1 + tg² = 1/cos²`
- весь блок высоты к гипотенузе (`CH² = AH·BH`, `AH = AB·cos²A`, …)
- медиана к гипотенузе = половине гипотенузы
- углы между высотой / медианой / биссектрисой
