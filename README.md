# ЕГЭ-навигатор формул

Карманный справочник для профильной математики ЕГЭ, задания **№1 Планиметрия**, **№2 Векторы**, **№3 Стереометрия**, **№4 Вероятность**.

Источник формул — банк [Решу ЕГЭ](https://math-ege.sdamgia.ru), не общий список из интернета. Каждая строка в карточке взята из реального решения и начинается с **ЕСЛИ**: при каком слове в условии её брать.

Человек открывает задачу, находит в условии слово (ромб, призма, касательная), открывает карточку и подставляет числа. Формулы короткие. Рядом одна ловушка: где обычно ошибаются.

## Что открывать

Готовый справочник, его и читать:

`out/ege_navigator_1_2_3.pdf`

Там оглавление с нажатиями, кнопки сверху страницы и закладки. Схема фигуры слева, справа условия, формулы, буквы, короткие шаги и ловушка.

Два других PDF — выгрузка задач с условием, рисунком и решением, чтобы разобрать тему целиком:

- `out/ege_task2_vectors.pdf` — все 58 задач №2
- `out/ege_task3_stereo.pdf` — все 315 задач №3

№4 уже внутри справочника: 65 задач, категория 166. №5–19 не входят, пока их прямо не попросили. Точка остановки для нового чата — первый раздел `AGENTS.md`.

## Как устроено

Справочник не правят руками в PDF. Правда лежит в `content/cards_1_2_3.py`. Сборка только рисует карточки.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/build_pdf.py
```

Нужен шрифт с кириллицей: `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf` (пакет `fonts-dejavu-core`).

Карточка — словарь: `section`, `title`, `figure`, `when`, `formulas`, `letters`, `steps`, `trap`. Формула задаётся так:

```python
F("V = S·H", "Ребро L наклонено к грани под углом α")
```

Первый аргумент — формула, второй — когда её брать. На PDF это строка «ЕСЛИ».

Ключ `figure` выбирает рисунок в `scripts/build_pdf.py`: `right_triangle`, `box`, `prism`, `oblique`, `pyramid` и остальные. Новый ключ без функции рисования даёт пустой прямоугольник.

После правки карточек пересобрать PDF и проверить, что строка «Ловушка» попала в текст. Если её нет, карточка обрезалась.

Печатный адрес категории, он отдаёт все задачи, не пять штук:

`https://math-ege.sdamgia.ru/test?filter=all&category_id=ID&print=true`

## Чего справочник не обещает

Он покрывает повторяющиеся ходы банка, не любую случайную конфигурацию. Если в решении ход встретился один раз и в карточку не перенесён, его там нет. Новую формулу добавляют только после того, как она найдена в `data/raw_live`, с номером задачи. Из учебника в карточку ничего не дописывают.
