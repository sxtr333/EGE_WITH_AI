# Как править этот проект

Справочник для ЕГЭ, профиль, задания №1, №2 и №3. Читатель готовится по банку Решу ЕГЭ и сверяет справочник случайными задачами. Писать по-русски, коротко, без канцелярита.

## Источник правды

Формула попадает в карточку только если она есть в решении из `data/raw_live/`. Номер задачи пишется в комментарии к правке или держится в голове при проверке. Формулу из общей памяти, которой нет в банке, не добавлять.

Скачанный JSON сам по себе карточку не обновляет. После новой выгрузки нужно прочитать решения и перенести повторяющийся ход в `content/cards_1_2_3.py`.

Задания №4–19 не начинать, пока об этом прямо не попросили.

## Куда писать

- Карточки: `content/cards_1_2_3.py`. Функция `F(формула, когда)`.
- Рисунки карточек: `scripts/build_pdf.py`, ветка `wrap_draw`. Ключ `figure` в карточке должен совпадать с веткой.
- Сборка справочника: `.venv/bin/python scripts/build_pdf.py` → `out/ege_navigator_1_2_3.pdf`.
- Выгрузка задач №2 и №3: `scripts/build_vectors_pdf.py`, `scripts/build_stereo_pdf.py`.
- Полный банк категории качается печатной страницей `print=true`, скрипт `scripts/fetch_live.py`. Метод API, который отдаёт около пяти id, для полного банка не использовать.

PDF руками не редактировать. После сборки проверить `pdftotext`, что строка «Ловушка» этой карточки на месте. Если её нет, текст обрезан.

Название карточки должно совпадать со словом из условия. «Ромб», «треугольная призма», «наклонный параллелепипед» — отдельные карточки, даже если формула уже спрятана в соседней.

## Что уже зафиксировано

643 задачи: 270 планиметрия, 58 векторы, 315 стереометрия. У каждой есть решение. Рисунка на сайте нет у 74 задач.

Покрытие не стопроцентное. Справочник держит повторяющиеся ходы. Разовый чертёж, которого нет в карточках, честно называть пропуском и добавлять только из решения.
