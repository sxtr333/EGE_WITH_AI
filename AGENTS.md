## Откуда брать формулу

Единственный источник: `data/raw_live/t{1,2,3,4}_c{id}.json`. Для №4 файл один: `t4_c166.json`. В каждой задаче есть `condition`, `solution`, `formulas_raw`, `answer`, `figure_url`. Рисунки задач: `data/figures/t*_c*/{id}.svg`.

`data/raw/` — старая неполная выгрузка. Её не считать банком. `cards/01-pryamougolnyy-treugolnik.md` — черновик самого начала. Живые карточки только в `content/cards_1_2_3.py`.

Формулу из памяти, Википедии или «так обычно в учебнике» в карточку не писать. Сначала найти ход в решении, запомнить id задачи, потом добавить строку. Если в банке такого слова нет, сказать это прямо, а не рисовать пустую карточку из учебника.

Скачать категорию и «обработать» — разные вещи. Пока ход из решения не перенесён в карточку, его в справочнике нет.

Полный список задач категории даёт только печатная страница:

`https://math-ege.sdamgia.ru/test?filter=all&category_id=ID&print=true`

Скрипт: `scripts/fetch_live.py`. Он пишет в `data/raw_live/` и качает рисунки в `data/figures/`. Пакет `sdamgia-api` и `get_category_by_id` отдают около пяти номеров. Для полного банка их не использовать.

Сохранённый человеком HTML не использовать: картинки в нём битые. Качать живую страницу.

В alt-тексте формул сайта бывают уже сломанные фразы вроде «корень из д робь» с пробелом. Это исходник сайта, чистильщик это не чинит.

## Как устроена карточка

Файл `content/cards_1_2_3.py`. Список `CARDS`. Помощник:

```python
F("V = S·H", "Ребро L составляет с гранью угол α")
```

Поля карточки:

- `section` — раздел PDF и кнопка навигации
- `subtype` — подпись под названием, в PDF печатается
- `title` — то, что человек ищет в оглавлении. Должно совпадать со словом из условия
- `figure` — ключ рисунка в `scripts/build_pdf.py`
- `when` — одна строка, когда открывать карточку
- `formulas` — список `F(формула, когда)`
- `letters` — что обозначают буквы
- `steps` — три коротких шага
- `trap` — одна ошибка, которую уже делали в решениях
- `n` — сколько задач у подтипа. В PDF не печатается

На странице слева рисунок, справа текст. Строка формулы рисуется как «ЕСЛИ: …», под ней «→ формула».

Название карточки человек должен найти по слову из задачи. Если формула спрятана в общей карточке под другим рисунком, для него её нет. Так уже потерялись ромб, многоугольник, треугольная призма и наклонный параллелепипед. У каждой такой фигуры своя карточка и свой рисунок.

Первая карточка «Слово в условии → карточка» — указатель. Новое слово из условия добавлять и туда, иначе человек его не находит.

## Сборка PDF

Правка карточки сама PDF не меняет.

```bash
cd <корень репозитория>
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python scripts/build_pdf.py
```

Шрифт с кириллицей обязателен: `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf` и `DejaVuSans-Bold.ttf`. Пакет `fonts-dejavu-core`. Без него сборка падает.

Проверка, что карточка не обрезалась:

```bash
pdftotext -layout out/ege_navigator_1_2_3.pdf - | rg "Название карточки|Ловушка"
```

Строка «Ловушка» этой карточки должна быть в тексте. Высота карточки считается в `estimate_card_h`, потолок 200 мм. Если ловушки нет, карточка длиннее потолка: укоротить текст, не снимать ловушку.

Закладки: `bookmarkPage(..., fit="XYZ", zoom=None)`. Не ставить `zoom=0`: читалка уменьшает страницу в ноль.

Кнопки сверху каждой страницы, по порядку: Оглавление, Счёт, №1, №2, №3, №4, ax², Впис. «Счёт» ведёт в раздел «Как посчитать». «№1» ведёт на таблицу углов, потому что у неё section «№1. Планиметрия» и она стоит раньше «Как посчитать». «ax²» — карточка «Полное квадратное уравнение». «Впис» — «Вписано · пирамида, конус, основание». Новая кнопка добавляется в `_nav_targets()` в `scripts/build_pdf.py`. Кнопок больше не плодить, пока полоска влезает в ширину A4.

Оглавление на обложке: каждое название карточки — ссылка на закладку `card-{i}`.

## Рисунки карточек

Ключ `figure` должен быть одной из веток `wrap_draw` в `scripts/build_pdf.py`:

`right_triangle`, `right_alt`, `isosceles`, `triangle_area`, `parallelogram`, `rectangle`, `rhombus`, `square`, `equilateral`, `quad`, `trapezoid`, `hexagon`, `algebra`, `circle_angles`, `tangent_chord`, `incircle`, `circumcircle`, `vector`, `cube`, `box`, `prism`, `oblique`, `pyramid`, `cylinder`, `cone`, `sphere`, `composite`, `combo`, `prob`.

Неизвестный ключ рисует пустой прямоугольник. Ромб нельзя рисовать как параллелограмм: человек решает, что карточки нет.

`_poly` принимает список пар `(x, y)` или плоский список `[x, y, x, y]`. Если код делает `pts[0][0]` сам, точки должны быть парами. Плоский список в этом месте уже ронял сборку на четырёхугольнике.

Рисунок задачи из банка в справочник не вставляется. В справочнике схема собирается кодом. Настоящие SVG остаются в `data/figures` и идут только в PDF выгрузки задач №2 и №3 через `svglib`.

№2, пять карточек: координаты; длина и операции; скалярное и угол; прямоугольник, ромб, треугольник; разложение по двум векторам.

№3: куб; прямоугольный параллелепипед; наклонный параллелепипед; фигура внутри параллелепипеда; составной многогранник; призма; треугольная призма; пирамида; боковая поверхность пирамиды; цилиндр; конус; шар; комбинации шар/куб/цилиндр; комбинации конус и призма; вписанные пирамида, конус, основание.

№4, десять карточек: m из n; частота и округление; монета; два кубика; уже известно; круглый стол и одна группа; порядок троих и кто сильнее; поровну, копилка, код; сколько исходов; не A и по шагам. База всех 65 задач: `P = m/n`. «Не будет» — это `(n−k)/n`. После слов «известно, что» делить на оставшиеся исходы, не на 36. Круглый стол: одну посадили, `P = 2/(n−1)`. Код с двумя одинаковыми цифрами: всего 270, не 1000. Число способов выбрать k из n: `C(n, k) = n! / (k!·(n−k)!)`. Три из шести: `6·5·4 / (3·2·1) = 20`. Ровно k орлов: это C, всего `2ⁿ`. Порядок n разных: `n!`. Противоположное: `P(не A) = 1 − P(A)`. Уже известно A, ищут B: `P(B|A) = P(AB) / P(A)`. Без возврата знаменатель каждый раз на 1 меньше. Несовместные пути складывают. Сумма двух кубиков и сумма 6 на трёх кубиках в решениях остаются списком пар, формулы числа пар в банке нет.

Наклонный параллелепипед в каталоге отдельным пунктом не называется. В банке это задача 27104: грань-ромб, ребро под углом к грани. Формулы: `V = S·H`, `H = L·sin α`, `S = a²·sin γ`. Высота не равна ребру.

Треугольная призма — не отдельная категория, а 27 задач внутри призмы. Прямоугольное основание: `S = ab/2`, `V = S·H`, `Sбок = (a+b+c)·H`. Правильная: `S = a²√3/4`. Средняя линия основания, плоскость параллельна ребру: объём отсечённой `/4`, боковая поверхность отсечённой `/2`. Это разные числа.

## Как отвечать на «есть ли формула» и «почему нет фигуры»

Человек присылает скрин задачи и спрашивает, решит ли он её по справочнику.

1. Найти слова условия в названиях карточек.
2. Открыть `content/cards_1_2_3.py` и найти строку формулы, не вспоминать её.
3. Если строки нет — сказать, что нет, и назвать, какого хода не хватает.
4. Добавлять строку только если он просит добавить, и только из решения этой задачи или такого же хода в `data/raw_live`.
5. После добавления пересобрать PDF и проверить ловушку.

Не говорить «можешь решить все 643». Справочник закрывает повторяющиеся ходы. Один редкий чертёж может потребовать две или три карточки сразу. Если для последнего числа нет строки, например `sin 30° = 1/2` не подставлен, задача для него не решена, даже если площадь `½ab sin C` на месте.

Частые ложные «дыры», которые уже закрыты отдельной карточкой и рисунком: ромб, квадрат, прямоугольник, равносторонний треугольник, четырёхугольник, многоугольник, треугольная призма, наклонный параллелепипед, фигура внутри параллелепипеда, вписанные тела. Прежде чем сказать «этого нет», поищи название в `cards_1_2_3.py`.

Регулярка по слову «косинус» врёт: она цепляет «минус 2» внутри других формул и раздувает счётчик теоремы косинусов. Считать вхождения теоремы по тексту решения, не по шумной регулярке.
